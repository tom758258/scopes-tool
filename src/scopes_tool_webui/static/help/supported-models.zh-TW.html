支援型號

English

本文件記載 Core Runtime 的正式型號支援政策。命令層級行為仍記載於 ../cli/README.md 與 ../contracts/。

Capability Profile 描述 Runtime 支援且受保護的功能範圍，並不偵測儀器選配或授權。 硬體或選配不可用時，仍以實機錯誤為準。

標準實體型號身分

Scopes Tool 為已註冊的 Keysight InfiniiVision 與 Tektronix 型號提供廠商中立的 Product API。標準實體型號 Registry 包含：

標準實體 Model ID 製造商 Model Series Capability Profile ID Driver ID
keysight-dsox2004a Keysight Technologies DSOX2004A 2000X keysight-infiniivision-2000x keysight-infiniivision
keysight-dsox3024a Keysight Technologies DSOX3024A 3000X keysight-infiniivision-3000x keysight-infiniivision
keysight-dsox4024a Keysight Technologies DSOX4024A 4000X keysight-infiniivision-4000x keysight-infiniivision
keysight-dsox4034a Keysight Technologies DSOX4034A 4000X keysight-infiniivision-4000x keysight-infiniivision
tektronix-tbs2074 Tektronix TBS2074 TBS2000 tektronix-tbs2074 tektronix
tektronix-tds2024b Tektronix TDS2024B TDS2000B tektronix-tds2024b tektronix
tektronix-tbs1052b Tektronix TBS1052B TBS1000B tektronix-tbs1052b tektronix

標準註冊識別實體型號；每個已註冊型號明確選擇其 Runtime Capability Profile。

每個已註冊實體型號都有無硬體的一致性檢查，涵蓋廠商身分、能力查找與驅動選擇。 啟用模擬器的型號亦使用模擬器身分解析。

Core 依各實體型號註冊的 Driver ID 明確選擇驅動。已註冊的 Runtime Driver 為 keysight-infiniivision 與 tektronix。Live 選擇依偵測 *IDN? 解析出的標準實體型號， 規劃與預期身分不得覆蓋。未知廠商、實體型號，以及缺少或未註冊的 Driver ID 一律拒絕。

VISA Backend 邊界

Product Live 支援精確取決於偵測到的實體型號、VISA Transport 與 Backend。 連接儀器的 *IDN? 身分具權威性；規劃 Profile 或 Backend 選擇器不會授予型號或功能支援。 下列連線已開放支援的 Core Product 操作：

標準實體 Model ID System VISA USB System VISA TCPIP @py TCPIP
keysight-dsox2004a 開放 未開放 未開放
keysight-dsox3024a 開放 未開放 未開放
keysight-dsox4024a 開放 開放 開放
keysight-dsox4034a 開放 開放 開放
tektronix-tbs2074 開放 開放 開放
tektronix-tds2024b 開放 未開放 未開放
tektronix-tbs1052b 開放 未開放 未開放

所有型號的 @py USB 均未開放 Product Live。只有上表核准的型號／Transport／Backend 組合已開放；GPIB、ASRL、Bluetooth（@bt）及明確自訂 VISA Backend 均未開放。 預設或 system_visa 選擇器明確載入並驗證已安裝的 IVI VISA Runtime，不會退回 @py。 明確指定 @ivi 歸類為自訂 Backend，請改用預設 System VISA 選擇器。

能力、參數限制、已安裝選配與儀器原生狀態仍決定已開放連線內可用的操作。 連線開放不會自動啟用依賴選配或其他不支援的命令。模擬與 Dry-run 不開啟實際 VISA Session。

貢獻者驗證與診斷

下列 @py USB 連線僅限受控的 CLI Validation Mode，未開放 Product Live： keysight-dsox2004a、keysight-dsox3024a、keysight-dsox4024a、 keysight-dsox4034a、tektronix-tbs1052b。 Validation Mode 也允許三個已開放的 @py TCPIP 組合，但絕不覆蓋偵測型號、能力或安全要求。 WebUI 與 Worker 不可啟用此模式。identify 與 list-resources 是連線診斷，並非 Product 授權。

直接呼叫 Python Oscilloscope.open() 仍是低階 Session 介面，而非 Product 政策入口。 Product CLI 與 Core 執行路徑在改變儀器的操作前執行此矩陣限制。

Runtime Profile

Core 將 Live *IDN? 的廠商與型號欄位解析為標準實體 Model ID，再使用註冊的 Capability Profile ID。Dry-run 的 --model 使用標準實體 Model ID。 已註冊的 Keysight 與 Tektronix 型號皆可模擬；模擬器的廠商／型號 IDN 欄位與能力 來自相同 Registry 項目。

Profile ID Series 註冊型號 類比 Channel
keysight-infiniivision-2000x 2000X DSOX2004A 4
keysight-infiniivision-3000x 3000X DSOX3024A 4
keysight-infiniivision-4000x 4000X DSOX4024A, DSOX4034A 4
tektronix-tbs2074 TBS2000 TBS2074 4
tektronix-tds2024b TDS2000B TDS2024B 4
tektronix-tbs1052b TBS1000B TBS1052B 2

僅與 DSO-X 或 MSO-X 系列相似的型號字串不足以選擇能力。 未註冊名稱如 DSOX4054A，以及原始型號如 DSOX4024A，皆不可作為 --model 值。

Live 執行的能力只來自實際 *IDN? 廠商與型號解析的標準實體身分，規劃身分不可覆蓋。 Live Worker 將 --model 視為預期標準實體 Model ID；若與偵測身分不符， 在命令專屬 SCPI 前即失敗。

能力摘要

Tektronix Profile 僅允許下方型號支援章節記載的既有操作子集。三者皆支援 BYTE 波形擷取、 型號專屬單來源量測、通道電壓 Offset、原生狀態工作流程、依能力限制的擷取檢查與清理， 以及型號專屬 Sequence 子集。TBS2074 支援原生黑底 PNG 截圖、Smoke 流程及儀器端 Setup／Reference／檔案儲存；TDS2024B 支援明確 BMP 截圖，TBS1052B 支援透過 USBTMC 的明確 JPEG 截圖。TDS2024B 與 TBS1052B 不提供 Setup、Reference Memory 或儀器端儲存公開操作。三者均不支援正規化的 check-error。 Tek 工作流程狀態與 Keysight 正規化 System Error Queue 分開。

Core 擴充邊界請見新增型號 (docs/core/adding-a-model.md)。Tektronix Dry-run 與有狀態模擬器 對允許的操作使用 Tektronix 命令語法，但模擬不代表實機支援。 這些 Profile 不提供訊號 Preset 或 System Error Queue 注入。

Tektronix 型號支援

已註冊的 Tektronix 型號使用既有 Scopes Tool 公開契約；本節記載個別型號的硬體邊界。 Driver 方法、模擬器回應、Capability Flag 或 WebUI 顯示設定均不能證明實機支援。

支援用語具有規範性：

  • SUPPORTED：操作與明確列出的既有選項子集滿足公開契約，包括必要回讀與完成條件。 未列選項仍不支援，子集不會建立 Tektronix 專屬公開 Enum。
  • PARTIAL AGGREGATE：只適用於契約已允許不可用欄位的既有唯讀投影。 不支援的原子查詢會跳過，不會先嘗試再捕捉錯誤。Nullable 欄位不授權部分 Setter、 產物、量測或工作流程；Raw／來源欄位仍描述實際執行的操作。
  • UNSUPPORTED：無法提供必要語義或結果。必要回讀絕不以回傳 Setter 參數、 虛構值或空字串冒充硬體狀態。

公開驗證與手冊硬體限制均適用。支援的動作仍可能回報儀器錯誤、無可用波形、缺少儲存或逾時。 TBS2074 的權威手冊為 Tektronix TBS2000 Series Programmer Manual, 077-1149-02 Rev A； TDS2024B 與 TBS1052B 則為 TBS1000/B/EDU, TDS2000/B/C and related Series Programmer Manual, 077-0444-03 Rev B。 僅針對舊 TDS200 型號或 TDS2MM 模組記載的條件不適用於這些註冊型號。

Raw 欄位保留契約所需操作的實際儀器回應，回讀必須描述正在查詢的設定，而非相關設定。 未識別或超出子集的儀器狀態不會正規化為支援值。 允許的選項子集只適用於已接受並執行該選項的既有公開介面。 產物編碼、檔名與 Adapter 行為仍屬既有公開契約。

除非標示彙總、工作流程或主機功能，下表涵蓋原子動作及其既有 Query／Set 形式。 僅呈現用途的編輯器繼承其組成操作：acquisition-control、channel-scale-range、 external-trigger-range-level、front-panel-measurements、reference-waveform、 reference-labels、system-information、diagnostics、serial-decode、 serial-trigger、serial-lister。編輯器可顯示不可用欄位，但不啟用不支援動作； Adapter Alias 不會新增硬體功能。

Tek 命令後狀態邊界

使用透明命令後狀態介面的普通 Tek 操作，會在業務回應完成後執行一次內部 *ESR?。 只有 SESR 位元 5–2（CME、EXE、DDE、QYE）屬於操作錯誤； 單獨 PON、URQ、RQC、OPC 不表示失敗。

一般非量測後檢查不執行 EVENT?、EVMsg?、ALLEv?、EVQty?，不模擬正規化 System Error Queue，也不填入頂層 system_error。非零 Error Mask 使用既有結構化錯誤路徑， 保留 Raw SESR。因 *ESR? 為消耗式讀取，system-standard-event 恰好只讀要求的一次； system-clear-status、system-status-byte、system-opc 不額外隱含讀取 SESR。 後檢查不是完成等待，也不會讓不支援操作變成支援。capture 原子操作使用此介面； measure 與組合流程使用下方原生工作流程檢查點，不再重複讀取原子 SESR。

原生工作流程狀態

工作流程檢查點先讀 DESE?，要求啟用 Error Bits 2–5，再讀一次 *ESR?， 並在下次 SESR 讀取前消耗 ALLEv?。不改 DESE、ESE、SRE。 順序遵循手冊的消耗式 SESR/Event Cohort：後續 SESR 讀取可能丟棄前一批尚未讀取事件。 見 TBS2000 第 206–209 頁及 B1 第 3 章。

工作流程結果保留 system_error: null，以 post_command_status 呈現 tektronix-sesr 來源、原始 SESR／事件回應、解碼事件／類別、完整性與消耗式讀取旗標。 Sample 與 Sequence／Acquisition Step 使用相同表示法。Command、Execution、Device、Query Error Bits 會使檢查點失敗；僅資訊事件不會。設有 Error Bit 的警告，除下方量測例外外仍失敗。 格式錯誤、Queue Overflow（350）及不完整狀態一律拒絕並阻止後續流程步驟。 不可透過重試讀第二次 SESR 隱藏未讀或格式錯誤的事件批次。

Immediate Measurement 只有在值有效且有限、SESR 除 Execution Bit 4 外無其他錯誤位元， 且事件批次完整、僅含帶訊息的 540–549 量測警告時，才允許這些事件。 值、Raw SESR、事件碼與警告訊息保留在既有量測狀態欄位。 TYPE/SOURCE 與單位設定後的嚴格檢查點將先前工作與值查詢分開；還原另做嚴格檢查。 規則適用於 measure、sweep、log、until、觸發量測迴圈、Sequence 量測步驟及 Smoke 量測。 無效值、其他事件、混合錯誤及通訊失敗仍失敗。Tektronix Smoke 遇無效量測 Sentinel 也失敗； Keysight Smoke 將此列為警告的政策不變。Capture、Acquisition、Trigger、Cleanup 檢查點保留其錯誤規則。

Doctor 遇既存錯誤停止；其他流程依既有前置政策回報舊事件後繼續，不完整前置檢查一定失敗。 Cleanup 在明確要求下清除狀態，再驗證完成與原生狀態。 公開 check-error、query_system_error、drain_system_errors、 system-operation-status 仍不支援。

wait_for_current_trigger_completion 觀察目前擷取，絕不 Arm；single_wait Arm 一次後 委派等待。Triggered Workflow 組合一次 single 與目前擷取等待； Sequence wait-trigger 也不會默默再執行一次 single。

手冊歧義與排除的解讀

保留下列參考，避免歧義錯誤擴張支援：

  • TDS2000B/TBS1000B 手冊第 2-98 頁將 BMP 列入 TBS1000B HARDCopy:FORMat 語法並適用 USB-file/USBTMC；第 2-99 頁卻稱 BMP 非 TBS1000B。因此 TBS1052B BMP 截圖仍不支援， 需權威釐清。另一方面，第 2-98 至 2-99 頁明確記載 TBS1000B JPEG， 第 2-96 至 2-102 頁記載 HARDCopy START 與 USB Device Port 路由， 因此支援獨立 JPEG 路徑但不開放 BMP。HARDCopy:FORMat? 不是 SAVE:IMAGE:FILEFORMAT 回讀；舊型號儀器端儲存仍不在公開操作內。
  • TBS2000 FFT 文件未建立公開原子結果所需 Full-span 換算或頻率參考（第 93–97 頁）。
  • TBS2000 Cursor 文件提及 Source 但無對應命令項目，因此 Selected-waveform Adapter 使用手冊 SELect:CONTROl 語義，包含選擇／顯示／擷取影響（第 67–73、161 頁）。
  • 部分 TBS2000 Trigger 範例與語法矛盾；僅允許獨立記載控制及明確 Runt 子集 （第 172、174、177–180 頁）。Pulse-width 只公開所選 less-than/greater-than Threshold， 不公開保留的獨立 Threshold 或 Range。
  • TBS2000 量測彙總範例顯示 Statistics/Indicator 欄位但未定義對應控制， 不構成公開 Measurement-statistics 或 Marker 顯示功能。

本節歧義不授權新增公開操作、Enum、波形換算、檔案系統 Helper 或支援政策。

因無必要 MSO／數位通道基礎，不支援 Bus Timing 與 Bus State；它們不在已啟用能力操作、 CLI 選項、Worker 命令、Core Builder 或模擬器行為內。

  • BYTE 與 WORD 波形擷取，保守安全上限 10,000 點。
  • 唯讀量測 Helper 與截圖擷取。
  • 量測控制可清除量測、啟用／查詢 Measurement Marker、選擇類比來源及 MAIN/ZOOM/AUTO/GATE 視窗。ZOOM 要求已顯示 Zoomed Timebase，未知時 AUTO 較安全。僅寫 source1 時，回讀可保留 source2。
  • 進階量測統計限 3000X/4000X。Core 查詢儀器累積的 Current/Minimum/Maximum/Mean/ Standard-deviation/Count，並控制 Statistics Mode、LCD Display、Maximum Count、 Relative Standard Deviation、Reset、Manual Increment；2000X 不宣告此能力。
  • Reference Waveform Helper 管理槽位 1、2；啟用一槽時儀器可能關閉另一槽顯示。
  • DVM 支援 Enable、類比來源、dc/dc-rms/ac-rms 電壓模式、Auto Range、目前電壓與彙總查詢。 DVM 可能需要選配／授權；不支援 DVM Frequency、獨立 :COUNter 或 :MEASure:COUNter。
  • DEMO 輸出彙總及個別 Output/Function/Phase Helper。DEMO 依選配／硬體；Profile 在開 Session 前限制手冊 Function 名稱，缺少選配／硬體仍以實機錯誤為準。
  • WGEN Output/Function/Frequency/Amplitude/Offset/Load 與彙總查詢。 2000X/3000X 用 :WGEN，4000X 僅 Generator 1 的 :WGEN1。 可設 Function：sine、square、ramp、pulse、noise、dc。
  • Serial Bus 彙總 Query、Mode、Display 與 UART/I2C/SPI/CAN 基本協定設定。 Profile 限制 Bus 數與可設模式。Decode 可能需授權，Core 不偵測授權，保留選配／硬體不可用錯誤。
  • Serial Trigger 在相同 Profile 提供手冊共用 I2C/SPI/CAN 子集，不新增 Capability 欄位； Profile 仍限制 Bus 數與協定可用性。
  • Waveform Search State/Count Query 與 Profile 限制的 Mode 設定；不支援模式在送 Search SCPI 前拒絕。
  • 儀器端 SAVE 提供目前目錄／Base Name、Image 設定／啟動、Waveform 設定／啟動。 三種 Profile 皆有唯讀 Maximum-length Mode。設定波形長度最少 100 點，實際最大值依儀器／型號。
  • 類比通道標籤、Display Label、Display Annotation。
  • Core/CLI/Simulator/Worker 支援已記載單次觸發命令，包括 trigger-tv 基本 TV/Video Set/Query。
  • DSO-X 2000X/3000X/4000X 依 Operation Status Condition Run Bit 判定觸發擷取等待。

明確截圖格式僅開放 4000X，因其格式傳輸使用手冊的 :HCOPY:SDUMp 命令族。

三種 Profile 皆支援 search-state 與唯讀 search-count。 search-mode 先啟用 Search 再設 Mode；4000X 可用 search-event 導覽事件。 Serial Search 提供 UART/I2C/SPI/CAN 專屬搜尋控制；2000X 支援 Bus 1，3000X/4000X 支援 Bus 1、2。 必須先用對應 Serial 命令設定所選 Bus。

  • 2000X/3000X Channel Label 最多 10 個可列印 ASCII 字元。
  • 4000X Channel Label 最多 32 個可列印 ASCII 字元。
  • 2000X/3000X Annotation 為單一無索引槽位，不支援 X/Y 位置。
  • 4000X Annotation 支援索引槽位 1–10 與 X/Y 位置。
  • 4000X 支援受限制的 delay 配對量測；2000X/3000X 因 Delay Query 依賴量測定義狀態，不公開此 Helper。

Raw Waveform Points Mode 維持停用。已註冊 2000X/3000X/4000X Profile 可查詢 Segmented Memory、 明確設定模式／次數，並執行有限次單通道 segmented-capture。 手冊次數範圍：2000X 為 2–250，3000X/4000X 為 2–1000，實際最大值可能因記憶體深度更低。 Segmented Memory 可能需要 SGM 選配／授權；Capability Flag 允許此手冊命令族路徑， 不表示選配已安裝。Segmented Capture 不連續擷取、不還原狀態、不停用 Segmented Mode、 不強制觸發、不合併 CSV，也不做儀器端 Save/Export。 Serial Decode 能力代表命令族可用，不代表已安裝授權。

Serial 彙總回應保留 Raw。協定設定僅提供基本 UART/I2C/SPI/CAN Source/Decode。 Serial Lister 新增全域 Display/Reference 控制，透過 :LISTer:DATA? 匯出電腦端 Raw CSV； 不解析協定專屬 CSV，也不支援儀器端 :SAVE:LISTer。 Serial Search 在設定相符 Bus 後提供 UART/I2C/SPI/CAN 專屬搜尋控制。 Lister bus2 在 2000X 不可用，3000X/4000X 可用；2000X 的 all 仍有效。
