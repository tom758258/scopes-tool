Rebuilding the Windows application with a modified zeroconf
-----------------------------------------------------------
Use a Windows x64 development environment with Python 3.13 and Node.js 22,
matching the GitHub Actions Windows release toolchain.

1. Get the Scopes Tool source matching your distributed application version,
   and the zeroconf 0.151.5 source from the upstream tag above. Build your
   modified zeroconf into a compatible Windows wheel. Keep its package
   metadata version at 0.151.5 to match this notice and the build version check.
2. From the Scopes Tool source root, install the locked development environment:

       uv sync --python 3.13 --all-extras --locked --link-mode=copy

3. Replace the installed zeroconf with your modified wheel:

       uv pip install --python .venv/Scripts/python.exe --no-deps --reinstall <MODIFIED_ZEROCONF_WHEEL>

4. Rebuild the Windows release with that modified installed library:

       powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/build_release.ps1

   Do not run "uv sync" between steps 3 and 4; it may restore the unmodified
   locked wheel. Your rebuilt distribution is not an official Scopes Tool build.
